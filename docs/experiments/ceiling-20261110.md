原PDF SHA256：`b495e50a886acaa7ead1ef29712a76dc2e5213b3999a3d0d5987c063ca06677f`。

`ceiling = (tau_best / tau) * (T_prof / T_floor) * (T_step / T_prof)`。

正文定义tau_best为同一lattice上最佳节点预算的best-first树接受量；各kernel类floor为
`max(FLOPs / (0.60 * dense_peak), bytes / (0.90 * bandwidth))`。
