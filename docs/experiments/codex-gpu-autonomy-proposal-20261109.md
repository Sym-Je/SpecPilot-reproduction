# 下一阶段提案：Codex 最小真实 GPU 自主实验

日期：2026-11-09。**仅方案，未获执行/资源授权，无任务 UUID。**
前置：[权限收口](codex-boundary-20261109.md)、[CPU 自治](agent-autonomy-plan-20261109.md)。

## 目标

证明研究决策确实来自 agent：Master 自主选择一个方向并分配预算，direction 自行提出实验、
生成代码、请求执行，并根据真实 GPU 输出迭代；Master 根据证据决定继续/停止。
主助手只建设通用执行入口和审计，不再代做接受历史预测研究，不预设 VERIFY 优化。

本阶段是有限 GPU 自治验收，**不是完整 RSI、sealed 验证、优化发现或论文数字达标验收**。
没有收益、证据不足、实验失败均可正常结案，但不能因此声称研究能力或性能已验证。

## 主要流程

1. **通用执行链先验收。** 复用现有工具，把受限角色的结构化实验请求交给可信执行侧；
   复用已有 stock/candidate 启动与审计，不另建调度平台。现有 `exp/codex_boundary.py` 是权限探针，
   不是现成的 Master/direction GPU driver；必须接上角色任务和反馈，不把探针改名冒充研究。
2. **CPU fixture 先挡住危险动作。** 检查角色/轮次、授权源码快照、只读输入、超预算拒绝、
   重复/不明确提交的查重与停止，以及失败输出反馈。fixture 不计真实研究或 GPU 通过。
3. **由 Master 立项。** 只给授权 stock、公开聚合证据、工具协议和预算；不提供作者 final 实现、
   sealed、旧对话或人工指定的优化答案。Master 选 1 direction，direction 自主写最小实验和判据。
   研究判据不能改写 controller 的正确性/晋升规则。
4. **可信侧提交并跟踪。** 按 northjob-submit skill 核对当时 CLI、具体镜像、项目/namespace/queue/
   toleration 和模型只读挂载；冻结实际源码/配置/输入。按任务名查重，展示完整命令和总 GPU 数后才提交一次。
   不确定返回先查询，不盲目重提；成功需服务端 code==200 且有 UUID。
5. **direction 自主反馈迭代。** 反馈真实退出码、stdout/stderr 摘要、产物索引和剩余预算。
   由 direction 决定解释、修改、继续或停止；执行侧不替它改研究脚本。若申请第二次运行，仍使用剩余总预算。
6. **Master 结案、controller 独立裁判。** 若有可实施候选，必须 option 默认 stock，先正确性再配对性能验收；
   使用既有 controller，不在本阶段改判据或自动晋升。缺少所需验收/预算则明确留待下一阶段。
   归档代码身份、动作链、资源与证据，更新主页/计划/交接并同步私有 GitHub。

## 资源与边界（提案，不是授权）

- 最多同时 **2×H100 80GB**，总预算 **2 GPU 小时**，最多 2 个明确区分的任务尝试。
  所有尝试/冷启动/失败均计费；2 卡全时运行最多约 1 小时，还须为失败和收尾保留预算。
  不依赖计时器单点保证预算：可信侧设截止时间、监测实际状态，结束或超限即停止并核实资源释放。
- 真实模型最多 16 个请求，broker 最多 24 个动作、4 次隔离 CPU 实验；预算由可信侧维护，角色不能自报扩额。
- 镜像不猜测；先核对既有确认镜像是否满足当前依赖，再向用户确认本次具体身份及资源。
  项目/namespace/queue/toleration 是不同字段，不能沿用 CLI 默认项目或把池准入当专属调度。
- 诊断可按实验需求申请 1 GPU，但不得据此报配对加速；性能比较必须双卡同请求、fresh server、物理互换，
  统计由 controller 产生。样本与输出协议在运行前冻结，不看结果再改变分组/判据。
- 研究进程不持有 NorthJob 凭据。Codex 模型传输保留自身必要认证/联网，不等于任意网络流量已被隔离；
  研究 CPU 实验继续禁网络/子进程/设备。GPU 研究进程必须另验边界，不能照搬本机 CPU 探针结论。
- 不读取 sealed、不修改 controller/规则/账本，不读取 final 实现，不继续 DSH 或取消的补采，不自动写记忆或正式晋升。

## 通过与停止条件

**工程通过：**真实角色请求 → 实际 GPU 启动 → 真实实验结果/失败反馈 → direction 决策 → Master 复核，
全链可追溯；资源入口不重复提交且不能突破预算；独立审计能绑定角色代码与实际产物。
仅 code200、仅进程启动、仅 CPU fixture、仅模型评论均不算此链通过。

**科学结论另报：**是否有足够独立证据、是否形成候选、是否经 controller 正确性/配对验收，分别报告。
不为“工程通过”制造收益或强制 direction 在无依据时继续实验。

**立即停止：**权限探针失败、凭据/受限数据边界无法落实、提交身份不明且查重仍不能确认、
达到预算/尝试/模型动作上限、输入或执行源身份不匹配、资源无法可靠收回。
保留失败与已消耗预算，必要时请求用户处理；不自行换镜像/扩额或恢复旧任务。

## 合理性自检

先保护边界、再接真实执行；只建设研究所必需的桥接，不再扩建框架。
研究内容由 agent 决策，提交权限与裁判留在可信侧；工程验收与科学收益不混淆。
若现有入口不能承载角色轮次或 GPU 隔离，报告具体缺项，不以提示词承诺替代实际拒绝。

执行前将新增测试及验收命令写入独立阶段记录；本提案不会解锁当前恒 blocked 的 GPU 离线预检。
